Fixes

  • A remote project's own ssh login now offers to save the password you type and autofills it next time. (#455)
  • Options typed to ssh in a pane, such as ssh -p 2222 host, now reach ssh instead of being taken as the host name when ghostty's ssh shell integration is on. (#455)
  • The Save Password? bubble names an ssh login by what you typed, without the options Macterm adds to it. (#455)
  • Desktop widgets keep their rounded corners when liquid glass is off. (#454)
  • Desktop widgets can be placed in every empty spot beside the system's own widgets and line up with them, even while windows cover the desktop. (#451)
  • macterm pane run clear --session <name> now types clear into that session's pane instead of typing the whole line into the current pane. (#457)
  • Settings → Passwords now calls its default Touch ID option "Once per app launch", which is when it asks again. (#458)

Notes

  • New desktop widgets open at 3×3 in the middle of the screen, and the size presets are gone; resize a widget from its edges while editing it. (#454)
  • macterm pane run now types everything after -- exactly as given and refuses any other option it doesn't know, so a script running macterm pane run ls -la must write macterm pane run -- ls -la. (#457)

Thanks to @thdxg for this release.
