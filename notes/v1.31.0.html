What's New

  • Password manager: Macterm offers to save passwords you type at terminal prompts and autofills them next time. (#444, #455, #458)
  • Desktop widgets: put terminals on your desktop, alongside the system's widgets. (#445, #451, #454)

Fixes

  • macos-auto-secure-input now engages at password prompts in every pane. (#444)
  • ssh -p 2222 host and other ssh options now work in panes with ghostty's ssh integration on. (#455)
  • Selecting text at the start of a line no longer pops open the hidden sidebar's overlay. (#448)
  • macterm pane run no longer types its own flags, such as --session, into the pane instead of using them to pick the target. (#457)

Notes

  • macterm pane run now types words after -- verbatim and refuses any other dash-word before it: write macterm pane run --session X -- ls -la rather than macterm pane run ls -la. Plain words without dashes still work as before.

Thanks to @thdxg for this release.
