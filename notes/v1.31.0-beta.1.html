What's New

  • Terminals can now live on the desktop as widgets: a locked panel styled and sized like a system widget, whose session persists like a pinned tab's, created from File → New Desktop Widget, the palette, Settings → Widgets, or widget new. (#445)
  • Macterm can now save and autofill passwords typed at terminal prompts, offering right at the cursor and gated behind Touch ID, with a searchable list in Settings → Passwords. (#444)

Fixes

  • Selecting text at the start of a line no longer pops open the hidden sidebar's peek overlay. (#448)
